 Today, I worked on generating a text summary of a football match using real match data. I fetched match fixtures, statistics, and events from the Football API by sending HTTP requests. I organized the data into a structured format that included team names, stats, and key match events. Then, I created a prompt using this data to describe the match in detail. I used ChatGPT (GPT-4o) to generate a professional and engaging summary of the match from the prompt. Finally, I made the script interactive so I could pick different matches and view summaries as many times as I wanted.
